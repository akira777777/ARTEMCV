# План редизайна ARTEMCV

## Текущее состояние (проблемы)
- 5+ версий Hero компонентов
- 4+ версий галерей  
- Множество дублирующих эффектов (CursorTrail, FloatingParticles, BackgroundPaths, ParticleText)
- CSS файл 2000+ строк с конфликтующими стилями
- 5+ цветов конкурирующих за внимание

## Концепция редизайна (по принципам Awwwards/Codrops профи)
- **Стиль:** Minimalist Dark - чистый чёрный фон с одним акцентным цветом
- **Фокус:** Контент (проекты) на первом месте, эффекты вторичны
- **Типографика:** Один шрифт для всего (Inter или Plus Jakarta Sans)
- **Анимации:** Плавные, сдержанные - только там где нужно

## Цветовая палитра (упрощение)
- Background: #0a0a0a (почти чёрный)
- Surface: #141414 (карточки)
- Text Primary: #ffffff
- Text Secondary: #a1a1aa (серый)
- Accent: #10b981 (один цвет - emerald)
